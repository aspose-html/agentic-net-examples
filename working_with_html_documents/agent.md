## Common Code Pattern

```csharp
using System;
using Aspose.Html;
using Aspose.Html.Converters;
using Aspose.Html.Saving;
using Aspose.Html.Rendering.Pdf;
using System.IO;

class Program
{
    static void Main()
    {
        // 1️⃣ Load an HTML file (could be a URL or raw string as well)
        string htmlPath = @"C:\Samples\template.html";
        HTMLDocument document = new HTMLDocument(htmlPath);

        // 2️⃣ Bind / manipulate the DOM – example: inject a title
        var titleElement = document.CreateElement("title");
        titleElement.TextContent = "Generated Report";
        document.Head.AppendChild(titleElement);

        // 3️⃣ Convert to PDF with default options
        var pdfOptions = new PdfSaveOptions();
        string pdfPath = Path.ChangeExtension(htmlPath, ".pdf");
        Converter.ConvertHTML(document, pdfPath, pdfOptions);

        // 4️⃣ Optional render to PNG for quick visual verification
        var imgOptions = new ImageSaveOptions(ImageFormat.Png);
        string pngPath = Path.ChangeExtension(htmlPath, ".png");
        Converter.ConvertHTML(document, pngPath, imgOptions);

        Console.WriteLine("Conversion completed:");
        Console.WriteLine($"PDF → {pdfPath}");
        Console.WriteLine($"PNG → {pngPath}");
    }
}
```

*The pattern demonstrates loading, minimal DOM manipulation, conversion, and optional rendering while logging progress with `Console.WriteLine`.*

## Category-Specific Tips

### Key API Surface
- **Document creation & loading**: `HTMLDocument`, `HTMLDocument(string)`, `HTMLDocument(Stream)`.
- **DOM manipulation**: `CreateElement`, `AppendChild`, `InsertBefore`, `SetAttribute`, `GetAttribute`, `RemoveChild`, `QuerySelector`, `QuerySelectorAll`.
- **Styling**: `Style.*`, internal `<style>` blocks, CSS variables, external stylesheet linking.
- **Conversion**: `Converter.ConvertHTML`, `Converter.ConvertSVG`, `Converter.ConvertEPUB`, `Converter.ConvertMHTML`.
- **Saving options**: `PdfSaveOptions`, `ImageSaveOptions`, `DocSaveOptions`, `HTMLSaveOptions`.
- **Rendering control**: `PageSetup.AnyPage`, `Rendering.Pdf`, `Rendering.Image`, `ImageDevice`.
- **Sandbox & security**: `Sandbox.Scripts`, `Sandbox.Images`, `Sandbox.Network`, `ScriptsPolicy`.
- **Configuration**: `Configuration`, `AgentService.UserAgent`, `AgentService.UserStyleSheet`, `FontsSettings`.

### Rules
1. **Always dispose** `HTMLDocument` (or wrap in `using`) when loading from streams to free native resources.  
2. **Set DPI / Pixels‑Per‑Inch** *before* any conversion if you need non‑default scaling.  
3. **Apply CSS before conversion** – internal `<style>` or linked stylesheet must be attached to the document prior to `Converter.Convert*`.  
4. **Sandbox first** when loading untrusted remote pages: disable scripts/images/network as needed to avoid side‑effects.  
5. **Use `Path.Combine` / `Path.ChangeExtension`** for file‑path manipulation to stay OS‑agnostic.  
6. **Log with `Console.WriteLine`** – the most common API – to keep examples self‑contained and observable.  
7. **When batch processing**, reuse a single `Configuration` instance to avoid repeated font‑lookup or proxy setup overhead.  
8. **Validate external resources** (fonts, images) exist before conversion; otherwise `Converter` will silently omit them.  
9. **For unit conversions**, prefer `Unit.FromPixels` → `Length.GetValue` or `Unit.GetValue` to keep physical measurements accurate.  
10. **Always set `HtmlDocument.Encoding`** when dealing with non‑UTF‑8 sources to prevent garbled characters.

## Warnings

- **Template binding mismatches** – placeholders in HTML templates must exactly match the keys used in your code; otherwise `null` values will be inserted.
- **Missing external resources** (fonts, images, CSS) cause silent omissions in the rendered output; verify paths or embed resources.
- **File‑path issues** – using hard‑coded separators (`\` or `/`) can break on other OSes; always use `Path.Combine`.
- **Memory consumption** – rendering large HTML pages to high‑resolution PNG/PDF can exhaust memory; consider streaming or lowering DPI.
- **Sandbox restrictions** – disabling network or scripts may also block needed inline resources; test with the exact sandbox flags you need.
- **Concurrent conversions** – `Converter` is thread‑safe, but shared `Configuration` objects must not be mutated after first use.
- **PDF security** – when embedding custom ICC profiles or digital signatures, ensure the target PDF version supports them.
